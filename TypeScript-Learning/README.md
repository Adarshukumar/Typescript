# TypeScript-Learning — my personal TS notes & practice code

By **Adarsh** — every file here is my own hand-written study material.
Read one, run one, break one. That is how this folder got written.

## How to use

1. Follow `00_ROADMAP.md` in order.
2. Compile and run any lesson: `npx tsx 03_basic_types.ts` (or `npx tsc`).
3. `tsconfig.json` in this folder is configured for quick learning runs.
4. Finish with `PRACTICE_CHALLENGES.md`, then go read real code in the
   project folders next door.

## Files

- `00_ROADMAP.md` — my study order
- `01`–`32` — lessons: basics → type system → generics → advanced magic
- `CHEATSHEET.md` — syntax quick reference
- `PRACTICE_CHALLENGES.md` — 30 challenges
