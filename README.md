## 🗺️ My Learning Path

```
🏁 JS with types    →  basic types · inference · arrays · interfaces
🧱 The type system  →  unions · narrowing · enums · unknown/any/never
⚙️ OOP + Generics   →  classes · modifiers · abstract · <T>
🧰 Utility belt     →  Pick/Omit/Partial/Record · guards · discriminated unions
🧙 Type-level       →  keyof · mapped · conditional · template literals
🚀 Real world       →  modules · overloads · .d.ts · API & React typing
```

Then I jump into real code below 👇
